# Diagramas de la guía UML

Los archivos `.uml` conservan el modelo textual (PlantUML) y los `.svg` muestran una versión con separación amplia entre clases para leer las multiplicidades en GitHub.

Si cambias nombres, miembros o cardinalidades, **actualiza el par `.uml` / `.svg`** correspondiente. El SVG usa únicamente trazos y texto vectorial, por lo que puede editarse sin perder nitidez.

Solo se incluyen aquí los ejemplos cuya cardinalidad necesita más espacio. Los esquemas pequeños de `UML_GUIDE.md` siguen con Mermaid.
